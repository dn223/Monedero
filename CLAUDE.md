## Notas propias de Claude Code

- En Windows, si `docker` no aparece en una consola abierta antes de instalar Docker Desktop, abre una consola nueva (el PATH se carga al iniciar).
- Las rutas de este repositorio son cortas a propósito (`C:\src\monedero`); evita carpetas sincronizadas como OneDrive.
- Antes de un commit corre `dart run tool/check.dart`; no uses `--no-verify`.
